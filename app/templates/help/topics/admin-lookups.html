Lookup lists set the allowed values for an ad's Sales, Size, and Section fields. A fourth list, Billed, is ready for when Billed is added to the ad form.

How the lists affect the ad form

  • While a list is empty, its field on the ad form accepts any text and suggests values already in use.
  • Once a list has active entries, the field becomes a dropdown, and the system refuses any value that is not on the list.
  • Older ads with a value that is not on the list keep it, marked (legacy, not on the list), and can still be saved.

Each list works on its own, so you can finish Sales first and leave Size as free text until it is ready.

The summary page

Admin › Lookup lists shows each list with its number of entries, the number of different values on ads, and how many ads use a value that is not on the list. That last number shows how much cleanup remains.

Work in this order: first merge spellings that mean the same thing (for example "1/4 pg" and "1/4 page"), and then add the remaining values to the list. Otherwise, the list collects several spellings of the same value.

Managing one list

Choose Manage list. The page has two parts.

Entries on the list

  • Add one value, with an optional name or description in the second box. The value is what the ads store, for example FP. The description appears beside it in the dropdown, for example "Full page".
  • Change an entry's description, or clear Active to hide it from the dropdown, and choose Save. Deactivating keeps the value on existing ads.
  • Remove deletes an entry, but only when no ad uses it. For a value in use, deactivate it instead.

Values used on ads but not on this list

This part lists every value that ads use but the list lacks, most used first, with the number of ads. Tick the values to keep and choose Add ticked values to the list. Use Find to narrow a long list.

Some values cannot be ticked:

  • A value that differs from a list entry only by capitals, such as kh when KH is on the list. Merge it into the list's spelling instead.
  • A value longer than 50 characters. Merge it into a shorter value.

Rules

  • A list cannot hold two entries that differ only by capitals.
  • The system records every change to a list in the audit log.
