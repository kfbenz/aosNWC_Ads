Over the years, Access collected many spellings of the same value: KH, Kh, and kh for one sales rep, or 1/4 pg, 1/4 page, and quarter for one size. Merge spellings changes them all to one value, so reports and searches group them together.

Merging

  1. Open Admin › Normalization map (the page is titled "Merge spellings") and choose the field tab: Sales, Size, Section, or Billed.
  2. Use Find to narrow the list, for example 1/4. Each value shows how many ads use it.
  3. Tick every spelling that means the same thing.
  4. In Merge ticked values into, enter the value to keep. It can be one of the ticked spellings or a new one. The box suggests the lookup list's entries and the values already in use.
  5. Choose Preview merge.

The preview

The preview shows exactly how many ads will change, broken down by current spelling. Nothing has changed yet.

  • If the value to keep is not on the lookup list, the preview offers to add it to the list. Leave that ticked in most cases.
  • If the list already has the value with different capitals, the preview says so. Go back and use the list's spelling, so that the ads match the list exactly.

Choose Merge to make the change, or Cancel to go back.

What the merge records

  • The system changes each affected ad and records each change in the audit log, with the old and new value.
  • It saves the decision itself (old value, new value, who approved it, and when) in the normalization map. The Recent merges list at the bottom of the page shows these decisions.

A merge changes live ads, and it has no single "undo" button. To reverse a merge, merge the values back by hand, using the audit log to see which ads changed. Confirm the values with the business owner before large merges, and make sure a recent database backup exists.

Tips

  • Start with Sales, which has few values, to learn how the page works.
  • Size has the most spellings. Work through it in small groups with Find, for example 1/4, then 1/2, then col.
  • Capitals matter on this page: KH and kh appear as separate values so that you can merge them.
