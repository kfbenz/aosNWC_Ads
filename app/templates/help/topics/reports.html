The Reports menu holds the Access reports and the saved queries staff used most. Every report is available to all roles.

  • Commission by sell date
  • Publication by run date
  • Mailing labels by directory year
  • Advertiser lists
  • Exports
  • Printing labels

Commission by sell date

Lists the ads sold between two dates that carry a commission above 0%, grouped by Date Sold, with the amount and the commission earned on each. The totals appear at the top.

  1. Enter the Starting date and Ending date, and choose Run report.
  2. Choose Print / Save as PDF to print it, or Download CSV to open it in Excel.

Commission earned is the amount multiplied by Comm %. Ads with no commission or 0% are left out.

Publication by run date

Lists every ad that runs in one issue, sorted by advertiser, with numbered lines. Use it to check an issue's ads before it goes to print.

  1. Enter the Run date, or pick one of the recent issues from the list.
  2. Choose Run report. It prints in landscape.

Mailing labels by directory year

Produces mailing labels for every account whose Directory Years field contains the year you enter, sorted by advertiser.

  1. Enter the Directory year, for example 2026.
  2. Tick Include contact name to print the contact's name under the advertiser's name on each label.
  3. Choose Find accounts to check the list, then Open labels PDF.

Advertiser lists

Replaces the saved Access queries, such as Christmas advertisers, Easter billing, graduation, current advertisers, e-mail lists, and parish lists. An account must match every filter you fill in.

  • Ads that ran: a run date range, specific issue dates (for example 12/1/2025, 12/1/2024), text in the section (for example Xmas or grad), or a sales rep.
  • Accounts: text in the advertiser name or category (for example parish), a directory year, and the status boxes.
  • Output: one row per advertiser (an address list) or one row per ad (with amounts).

Choose Show list to see the results on screen, or Excel, CSV, or Mailing labels (PDF) to download them. The screen shows the first part of a long list; the downloads always include every row.

Example: last year's Christmas advertisers who are still current. Enter the December issue dates in Specific issue dates, type Xmas in Section contains, tick Current advertisers, and choose One row per advertiser.

Exports

Produces an Excel workbook with one row per advertiser and description and one column per run date, like the two export buttons on the Access Dashboard.

  • Export amounts: the total amount of the ads for each run date.
  • Export commission earned: the amount multiplied by Comm % for each run date, for every ad in the range, including 0%.

Printing labels

  • The labels fit Avery 5160 or 8160 sheets: 30 labels per sheet, 1" × 2⅝".
  • In the print dialog, choose Actual size (100%), not "Fit to page". Otherwise, the labels drift off the stickers.
  • To use a partly used sheet, set Start at label to the first empty position. Position 1 is the top left, and the count runs across each row.
  • Print one test page on plain paper and hold it against a label sheet before you print a large run.
