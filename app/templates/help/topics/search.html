Search works like the Access advanced search. It finds accounts using any mix of contact details, client information, and the details of their ads.

Filling in the form

Fill in only the fields you want to search on and choose Search. Empty fields are ignored.

  • Contact Information: account number, advertiser, contact, address, city, state, zip, phone, fax, e-mail, web site, and Directory Years.
  • Customer Information: category, special advertising opportunities, and notes, plus the status boxes (current advertisers, past advertisers, prospects, and e-mail list).
  • Ad Information: description, authorized by, sales, size, section, page, run #, bill number, and ad notes, plus Date Sold and Date Run ranges, an Amount range, and Comm %.

How text matching works

You typeIt finds
MaryThe text anywhere in the field: "St. Mary Parish", "Maryknoll".
St.*Values that start with "St.". The * stands for any characters.
*ParishValues that end with "Parish".
98?05 in ZipThe ? stands for exactly one character: 98105, 98205, and so on.

Capital and small letters match each other: seattle finds "Seattle".

Comm % takes a percentage, as on the ad form: enter 10 for 10%. Amounts take plain numbers, for example 100 to 500.

Match any field (OR) or all fields (AND)

  • OR (the default) finds accounts that match any of the fields you filled in. Use it to cast a wide net.
  • AND finds accounts that match all of them. In AND mode, the ad fields must all match the same ad: "Sales KH and Date Run in December 2025" finds accounts with a KH ad that ran in December 2025.

The status boxes always narrow the results, in either mode. Ticking Current shows only current advertisers.

Results and exports

The results list each matching account once, with its number of ads and last run date. Choose an account to open it. Above the results:

  • Export addresses to Excel and CSV download the addresses of every matching account, not only the page shown.
  • Mailing labels (PDF) produces Avery 5160 labels for every matching account. See Printing labels.

If nothing matches, try fewer letters with OR, or fewer fields with AND. Choose Clear to start again.
