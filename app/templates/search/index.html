How searching works
  • Type part of a value to find it anywhere in that field: Mary finds "St. Mary Parish".
  • Use * (any characters) and ? (one character) for exact patterns, as in Access: St.* finds values that start with "St.".
  • OR finds accounts matching any filled-in field. AND finds accounts matching all of them; ad fields must then match the same ad.
  • The status boxes always narrow the results, whichever you choose.
